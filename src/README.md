# Лабораторна робота №3 — Розв'язування систем нелінійних рівнянь

**Варіант 3**

```
sin(x + y) + y = 2,6x
x² + y² = 4            (x < 0, y < 0)
```

Точність ε = 10⁻³. Методи: Ньютона, простої ітерації, Зейделя.

## Структура

| Файл             | Що всередині                                              | Автор     |

| `common.py`      | константи, система F, Якобіан W, φ1/φ2, формат результату | Софія     |
| `main.py`        | запуск усіх методів, таблиці, порівняння, перевірка       | Софія     |
| `newton.py`      | метод Ньютона                                             | Вільгельм |
| `localization.py`| графік локалізації, контроль через `fsolve`               | Вільгельм |
| `iteration.py`   | МПІ, метод Зейделя, оцінка q                              | Діана     |

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Команда

- Софія — тімлід, інтеграція, звіт
- Вільгельм — метод Ньютона, локалізація
- Діана — МПІ, метод Зейделя, оцінка збіжності
